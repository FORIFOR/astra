# 会議の収録リマインダー（macOS）

Zoom、Microsoft Teams、Google Meet の会議画面で退出ボタンを検知すると、macOS の通知で収録開始を促す。初回の検知時に通知の許可を求める。Astra が起動していて、アクセシビリティと通知が許可されている必要がある。

- 「収録を開始」から既存の録音開始経路へ進む。「今はしない」や通知を閉じる操作では録音しない。通知本文のクリックは Home を開く。
- 4秒間隔で前面の対応アプリを確認する。同じブラウザ内の画面遷移も確認する。会議アプリの起動や参加前ページだけでは促さない。
- 会議中は一度だけ促す。録音中に検知した会議では促さない。会議画面で退出操作が12秒以上見つからなくなった場合、次の会議で再び促せる。
- アプリを切り替えたことや AX の取得失敗だけでは会議終了とみなさない。通知の開始操作時にも会議が続いているか確認し、古い通知で新たな録音を誤って始めない。録音のトグル操作は使わない。
- AX は退出ボタンの名前だけを判定に使う。会議本文は保存・送信しない。探索に時間・要素数の上限を設け、別スレッドで実行する。

対応判定はネイティブ Zoom / Teams、および Chrome・Safari・Edge・Arc 内の会議タイトルと日本語・英語の退出操作による。ブラウザの背景タブだけで始まった会議、取得できないボタン、他言語のラベルは未対応。終了画面を確認せず会議タブを閉じた場合、同じプロセス・サービスの次の会議で再通知できない場合がある。集中モードやOSの通知設定によって表示は抑制される。

実装検証: macOS unit tests 61件合格（新規8件: 対応サービス、退出判定、参加前/権限不明、重複、検出の瞬断、会議終了、録音中、アプリ終了）。3サービスの実会議での通知表示・操作は未検証であり、単体テストをその代用とはしない。既存の Dock 寸法・造形には変更がない。
