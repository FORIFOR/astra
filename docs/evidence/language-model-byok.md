# 言語モデルを端末で呼ぶ — 実測の記録

正本 §8・§21、UI/UX §22。測ったのは 2026-08-27、この端末（darwin 25.5.0）。

Astra は共通の API キーを持たない。利用者が持ち込んだ利用権で呼ぶ。
この記録は「持ち込みが実際に動くか」を、**実際に動かして**確かめたもの。

## 何を通したか

cloud の `HostLanguageModel` → 受け渡し → 端末の `LlmRuntime` →
`claude` CLI（2.1.246）→ 返事 → cloud 側で形と根拠を検査、まで通した。

| 呼び出し                 | 時間   | 結果                                                         |
| ------------------------ | ------ | ------------------------------------------------------------ |
| `llm.decompose`          | 5622ms | 下位クエリ 3 件。元の問いに無い話題は入らなかった            |
| `llm.extract_claims`     | 4815ms | 主張 3 件。**supportText はいずれも抜粋の中に実在**した      |
| `llm.contradictions`     | 4639ms | `{left:0,right:1}` の 1 組。言い換えだけの組は挙がらなかった |
| 検査つき `extractClaims` | 4306ms | 3 件すべて `snippet.includes(supportText)` を通過            |

抽出の実際の返り（一部）:

```
A社の2025年度の売上高は1,204億円だった  <- "A社の2025年度の売上高は1,204億円でした"
売上高は前年度比で12.3%増加した          <- "前年度比で12.3%の増加です"
```

**言い換えは claim 側だけに出て、supportText は原文のままだった。**
指示（「そのまま現れる文字列でなければならない」）が効いている。

## 壊れ方も実際に確かめた

| 起こしたこと           | 返ったもの                                                                      |
| ---------------------- | ------------------------------------------------------------------------------- |
| CLI が入っていない端末 | `llm.no_model` /「Claude Code を繋ぐか、お使いの API キーを登録してください。」 |
| CLI が異常終了         | `llm.crashed` /「Claude Code が応答しませんでした。」                           |
| 読めない返事（散文）   | `llm.unreadable_output` — **空の答えとして通さない**                            |
| サインインしていない   | `llm.not_signed_in`（分類は単体試験。実アカウントを落とさずに再現できないため） |
| 利用上限               | `llm.rate_limited`（同上）                                                      |

いずれも「使えないと言う」で終わる。**運営側のモデルへは落ちない。**

## 線引き

- `claude-code.ts` は Claude Code の資格情報を読まない。
  `~/.claude` も `ANTHROPIC_API_KEY` も触らない。呼ぶのは CLI そのもの
- 問いは**標準入力**から渡す。引数に置くとプロセス一覧から読める
- 端末が居ないときは `PAUSED_HOST_OFFLINE` で止まる。代役は出さない

## まだ測っていないこと

- 実アカウントでの `not_signed_in` / `rate_limited`。
  分類器は単体試験で押さえてあるが、**本物の出力で確かめてはいない**
- 長い調査（数十回の呼び出し）での通し時間。1 回 4〜6 秒なので、
  10 件の調査で 1 分前後になる見込みだが、**測っていない**
