## 見つけて直した問題

資料提供を「相手に依頼する」メモから、「資料を送付いたします・ご査収ください」と逆方向のメールが生成されました。業務文書にも創作用のsamplingを使っていたため、業務はtemperature=0、創作指定のときだけ従来の設定に分けました。担当・期限・依頼方向をプロンプトに明記し、観測した逆転と下書き表示の欠落を検査します。

検査で落ちたローカル生成の修正は既存の上限1回です。外部APIやCLIに自動で再依頼する変更はありません。修正後の30回では追加生成は発生しませんでした。

## 残った失敗

- 最初の実機実行で、バックエンドに成果物ができていてもWorkが通信切断表示になりました。「状況を確認」で既存の仕事が取得でき、再送は不要でした。
- 調査で、状態取得が200ms間隔＝最大300回/分となり、一般APIの300回/分枠をこれだけで使い切る構成を確認しました。ソースを1秒間隔に変更し、瞬断/502/503/504に限り最大2回、既存タスクのGETを再試行します。401/429やタスク作成・送信は再試行しません。1リクエストの接続待ちも10秒に制限しました。
- 実HTTPのローカル試験で、取得頻度制限・503からの復帰・再試行上限・401/429を再試行しないことを確認。core全42件、Agent Host全192件合格。ただし元の実機失敗のHTTPステータスは保存されておらず、同一原因とは断定しません。更新配布物での再現確認と自動復帰の完了は未達です。
- アプリ再起動時に初期Profile取得の失敗が表示されました。「あとでHomeへ」からWorkを復元しました。Google接続・キーチェーン回復はこの業務検証の合格に含めていません。
- macOS自体の再起動、Intel機、1〜2時間連続利用、メモリ計測、10KB/100KB入力、実クラウド/CLIの同一業務反復は未測定です。

## 再現

既存モデル `qwen3.5:9b` とOllamaを起動し、リポジトリ直下で実行します。モデルを自動ダウンロードしません。

```sh
node --import tsx scripts/verification/workplace-local-repeat.mts /tmp/genie-workplace-new-run 30
```

保存先は新規ディレクトリを指定します。実Macは[ローカル起動手順](../../../LOCAL_PREVIEW.md)を使い、[input.json](input.json)の依頼・メモをHomeに入力します。Workで内容を確認し、保存ダイアログからMarkdownを保存、アプリを終了して開き直します。

今回のモデル送信先はこのMacのOllamaのみ。外部モデルAPI費用は0 USDです。電力・端末費用・モデルダウンロードは含みません。外部API/CLIを選んだ別の利用時には、その提供元へ入力が渡り料金が発生し得ます。

sourceCommitは実行時のベースを示します。未コミットの修正を含む検証だったため、この証拠と一緒に提出したソース差分も条件です。結果を新しい配布DMG全体のrelease=go判定に転用しないでください。
