## 30秒版の草案

仮タイトル:「午前3時のコンビニ、なぜか出国審査がある」

| 時間    | 映像・動き                                                             | 台詞・音                                                     |
| ------- | ---------------------------------------------------------------------- | ------------------------------------------------------------ |
| 0–4秒   | 眠そうな客がコーヒーを置く。制服の店員がごく普通に手を差し出す         | 店員「パスポートお願いします」                               |
| 4–9秒   | 客の背後で、宇宙服の客たちが整然と列を作っている                       | 客「……ここ、コンビニですよね？」レジの電子音                 |
| 9–15秒  | 店員が客の交通系カードを読み取る。店内表示が搭乗案内に変わる           | 店員「はい。いつもの星でよろしいですか？」                   |
| 15–22秒 | 自動ドアの向こうに巨大な宇宙船と搭乗通路。コーヒー片手の客が立ち尽くす | 遠いエンジン音。客「いつもの、って何？」                     |
| 22–30秒 | 宇宙港を背に店員が紙袋を差し出す。接客のテンションは最後まで変えない   | 店員「お帰りの地球、温めますか？」間を置いて客の表情で終わる |

映像は写実的、店内照明は深夜のコンビニ、演技は真顔。既存チェーンのロゴ・既存作品の宇宙船は使わない。店員の服、客の顔・服、コーヒーカップ、レジの位置は共通の基準素材で固定する。

これはショットの意図と編集尺。生成モデルの対応尺へ調整し、長いカットは分割して編集する。台詞は音声対応モデルで生成するか、別音声として合成する。字幕や店内文字は読める位置へ編集で加える。

## 最初に確かめること

冒頭4秒の接客と客の反応、続く宇宙服の列が、説明文なしで通じるかを小さく試す。キャラクターや台詞が破綻していればキーカットだけを直す。この草案の面白さは未検証であり、完成品の人間による確認と公開後の実績で改善する。
