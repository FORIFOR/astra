# レビュアーへ渡す質問

**「UI はどうですか」と聞かない。** 何を見て答えたか分かる問いにする。

見せる順（同じ順で全員に）:

```
01-idle → 02-listening → 03-task-dock → 04-meeting → 05-meeting-notes → 06-workspace
```

## 聞くこと

1. **Clarity** — いま Astra が Listening / Thinking / Executing のどれか、1 秒で分かりますか
2. **Calmness** — いまの作業を助けていますか、画面を占領していますか
3. **Continuity** — 別の窓が開いたように見えますか、続いた一つに見えますか
4. **Context** — Astra が何を見ているか分かりますか。やめさせられますか
5. **Trust** — この Decision の根拠を 5 秒以内に確かめられますか
6. **Control** — AI が誤って始めたとき、考えずに止められますか
7. **Hierarchy** — 3 秒見て、最も重要な情報を説明できますか
8. **Efficiency** — 覚えたら速くなりますか。余計な手順はありませんか
9. **Craft** — 間隔・字面・揃えに粗さはありませんか
10. **Delight** — 動きは自然ですか。使いたいと思いますか

## 競合と並べるとき（素材が揃ってから）

製品名を**伏せる**。A / B / C として同じ場面を見せ、最後に聞く:

- どれが最も理解しやすいですか
- どれが最も邪魔になりませんか
- どれを最も信頼できますか
- 最も完成度が高いのはどれですか
- **同じ値段なら、どれを毎日使いますか**（Preference）

Preference は所要時間とは別の説得力を持つ。20 人以上なら、
触る順序を人ごとに入れ替える（順序の効果を消すため）。
