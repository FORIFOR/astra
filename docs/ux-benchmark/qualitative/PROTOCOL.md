# R01–R10 — 採点の前に必ず通す 10 の場面

**同じ順で、同じ言葉で、3 人全員に実施する。** 順や言い回しが違うと、
点の差が「人の差」なのか「聞き方の差」なのか分からなくなる。

所要 15〜20 分／人。

---

## 進行役の禁止事項（これが守られないと採点は無効）

- **説明しない。** 「⌥Space を押すと出ます」と言った時点で R02 は測れない。
- **誘導しない。** 「ここに出ていますよね？」は禁止。黙って待つ。
- **助けない。** 迷っている時間こそ記録する対象。詰まったら「30 秒経過」で次へ。
- **弁明しない。** 「そこはまだ実装していなくて」と言わない。感じたままを取る。

進行役が言ってよいのは、各 R の**指示文そのまま**と「ありがとうございます」だけ。

記録するもの: 答えた**言葉そのまま**、詰まった箇所、詰まった秒数。
要約して書かない。「分かりにくそうだった」ではなく「『これ何ですか』と言った」。

---

## 準備

```sh
pnpm dev:desktop          # release バンドルではなく dev で
```

- 権限は**未許可の状態から**始める（初回の印象を測るため）。
  済んでいるなら システム設定 → プライバシーとセキュリティ から Astra を外す。
- 他のアプリ（Finder / ブラウザ / Notion / Meet）を普通に開いておく。R09 で使う。

---

## R01 First impression

Astra を起動して見せる。**何も説明しない。**

> 「このアプリで何ができますか？」

30 秒後に答えてもらう。良い UI なら説明なしで伝わる。

記録: 答えた言葉。「分からない」も立派な結果。
効く軸: Clarity / Hierarchy

## R02 Voice discovery

> 「Astra に、いま開いている画面について質問してください」

説明禁止。⌥Space に辿り着けるか、辿り着くまで何秒かかったかを見る。

効く軸: Clarity / Efficiency / Context

## R03 Listening

音声を開始させる。動いている最中に:

> 「いま Astra は何をしていますか？」

**「聞いている」と即答**できなければ改善対象。
「たぶん…録音？」のような迷いも記録する。

効く軸: Clarity / Calmness

## R04 Agent

> 「明日の予定を調べてください」

実行中に**突然**:

> 「いま何をしていると思いますか？」

Task Dock だけで理解できるか。AI の思考ではなく**何をしたか**が読めるか。

効く軸: Clarity / Trust / Control

## R05 Meeting Start — いま最も重要

会議を開始し、**0 秒 / 10 秒 / 30 秒**の 3 回、同じことを聞く:

> 「この画面から何が分かりますか？」

3 回とも記録する。0 秒の答えが最重要。
少なくとも「**ちゃんと動いている**」と分かる必要がある。
「何も出ていない」「壊れてる？」が出たら FAIL 相当。

効く軸: Clarity / Hierarchy / Calmness

## R06 Provenance

生成された Decision を 1 件見せて、**それだけ**言う:

> 「AI が間違っていると思います。確認してください」

説明なしで Decision → 出所 → 文字起こし へ行けるか。何クリックかかったか。

効く軸: Trust / Control

## R07 Correction

続けて:

> 「実際には Windows を先に出すと言っていました」

その場で直せるか。別画面へ出て行かずに完結するか。

効く軸: Trust / Control / Efficiency

## R08 Recovery

間違った Action を開始させ:

> 「止めてください」

説明なしで Stop / Cancel / Undo できるか。迷った秒数を記録。

効く軸: Control

## R09 Calmness — 機械では測れない

Astra を出したまま **5 分間**、普通に仕事をしてもらう
（Finder / ブラウザ / Notion / Meet）。進行役は黙って見る。

5 分後:

> 「Astra が邪魔だと感じた瞬間はありましたか？」

**あった場合は「いつ・何をしていたとき」まで聞く。** これが Calmness の実体で、
焦点を奪った回数が 0 でも「邪魔だった」は起こりうる。

効く軸: Calmness / Continuity

## R10 Preference

> 「これを毎日使いたいですか？」

```
1 絶対に使いたくない … 4 どちらとも … 7 ぜひ毎日使いたい
```

**この 1 問だけは他の軸と別枠で集計する**（Daily-use preference）。

`reviews/<あなたの名前>.yaml` を雛形から複製して埋める。
R01–R10 の観察を先に書き、**そのあとで** 10 軸に点を付ける。
点を先に付けると、観察が点の説明に引きずられる。

```sh
bash scripts/qualitative-gate.sh
```
