## 公式ページに書いてあること（2026-09-05 取得・本文のみ）

**これは公式が書いている説明であって、製品を触って確かめた事実ではない。**

- ホットキー（既定は ⌥Space）で「画面の中央に小さなバー」が出る
- Quick AI は「ホットキー 1 つで、他のアプリの上に浮かぶ窓として出る」
- Screen Awareness（2026-08）: 前面のアプリや窓の文脈を AI Chat / Quick AI に渡す

### 取れていないもの

- ホットキー直後の**空の root 窓**の公式画像（掲載画像はどれもコマンド使用中）
- AI コマンドや Agent が**実行中**の面（進行が見える面）→ Task Running は公開素材では比較できない
- `ai-commands.png` は斜めに傾けた宣伝用レンダーなので採点には使わない
