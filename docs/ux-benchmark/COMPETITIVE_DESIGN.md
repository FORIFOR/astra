# PUBLIC_COMPETITIVE_DESIGN_GATE

公式の公開素材だけで比べる。**名前を変えたのは、比べられる範囲が違うから。**

公式素材は競合がいちばん良く見える条件で撮っている。そこから
「操作が速い」を導くと必ず有利に出る。**比べるのは設計だけ。**

## 比べてよいもの

```
information hierarchy     情報の階層
surface density           面の詰まり具合
visual craft              造形の丁寧さ
state legibility          状態が読めるか
control visibility        操作が見えているか
provenance visibility     出所が見えているか
screen occupation         画面の占有
feature/state coverage    どの状態を持っているか
```

## 比べてはいけないもの

```
操作速度 / time-on-task
クリックの発見率
完遂率
初回成功率
焦点を奪ったか
```

これらは実機でしか出ない（`EVIDENCE.md`）。

## 進め方

1. `<製品>/public/` へ公式素材を置き、`sources.md` に URL・取得日・版を書く
2. ブランド名を隠し、表示順を入れ替えて Vision Judge へ 10 回投入する
3. 上の 8 項目だけを順位付けさせる
4. Astra の勝率 >= 70% を目標にする

**ブランド名を隠す**のは、名前で点が動くのを防ぐため。
**順序を入れ替える**のは、並び順の効果を消すため。
