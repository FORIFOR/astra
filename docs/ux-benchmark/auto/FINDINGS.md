## 学んだこと

**10 件のうち 7 件が仕掛けの不備だった。**

とくに 7 は危なかった。実装を知らない評価者が 2 回続けて
「6 つのボタンを押したが何も起きない」と報告し、そのまま信じれば
「クリックが効かない」という**存在しない欠陥**を直しにいくところだった。
自分で作った的（`clicktest`）を押して初めて、届いていないのは道具のほうだと分かった。

検査の環境が製品と少しでも違うと、その差を製品の欠陥として記録する。
自動で直す仕組みを回すと、そのまま「仕掛けの穴を埋めるためのコード変更」を
生んでしまう。**直す前に、まず仕掛けが本番と同じかを確かめる。**

そのために足したもの:
- `idle-hold` は本番と同じ登録をし、`shortcut=true/false` を出す
- `shot` は「アプリが終わっている」と「窓が無い」を区別する
- 採取（golden / geometry）も本番と同じ状態にする
- Judge には OCR 照合があり、画面に無いものを根拠にした採点は捨てる

### 2 周目: 訂正の道（correction_discoverability 2.0）

| | base(A) | D 同じ行に「直す」 | E 右端に鉛筆 | F 右端に囲みボタン |

**全案 revert。** 訂正の道は確かに見えるようになった（2.0 → 5〜6）が、
3 案とも hierarchy と density を 1.0 落とした。行ごとに訂正の入口を常設すると、
面が混む——Judge 9 体が揃ってそう言っている。

### ここで分かった、計測のほうの限界

base では訂正は**行を押した先**に在る。静止画 1 枚にはそれが写らないので、
Judge は「無い」と読む。**2.0 は製品の点ではなく、計測の点だった。**

一枚の絵で測れるのは「見えているか」までで、「辿れるか」は測れない。
辿れるかは、実装を知らない評価者に**実際にやらせて**測る（`hold-meeting` と
Vision→AX の press を足したのはこのため）。

### 3 周目: 静止画をやめ、実際に訂正させた

`hold-meeting` + Vision→AX の press で、実装を知らない評価者に直させた。

```
visual_target_found          PASS  最初に選んだ対象が正解（行の ⌄ → 直す）
semantic_activation_success  FAIL  道具に文字入力の口が無く、打ち直せなかった
result_state_correct         FAIL
```

**Discovery は通っている。** 2 周目の 2.0 が計測の点だったことが、これで裏付いた。
Activation の失敗は道具の話で、UI の話ではない。分けて記録する意味がここに出た。

そして**本物の欠陥**が 1 つ出た。

| 見えたこと | 実際 |
| --- | --- |
| 「これは違う」でメモが消え、戻せない | **本当**。確認も取り消しも無く、しかも「直す」のすぐ隣に在って押し間違えやすい |

確認ダイアログで止めるのではなく、**戻せる**ようにした（§6 間違いを見つけた
場所で直せる）。消すと「「◯◯」を消しました ［元に戻す］」が出る。

直したあと J09 が**別の不具合を捕まえた**: 戻す実装が拾い直し（`ingest`）を
通しており、分類からやり直されて時刻と話者が失われていた。元の束へ戻すよう直した。

### 4 周目: 一体に見せる（continuity 5.0 / context 4.0）

Judge が両軸で「上の黒い塊が別窓に見える」と言ったので、そこを狙った。

**全案 revert。仮説が外れた。** 浮遊感を消しても continuity は上がらず、
H はむしろ下げた。context に至っては G も H も下がっている。

Judge の弁を読み直すと、context が低いのは**見た目ではなく中身**だった:

> 「どの会議・どのアプリ・誰なのかが分からない。『14:50 の会議』は時刻だけ」
> 「『AI が見ている資料』が、何の資料か言っていない」

直すべきは造形ではなく、**出所を名前で言うこと**。次はそこを埋める。

### 比べてよい範囲について

この周の base の context は 4.0 だが、J05 の周では 5.0 だった。
**問いが違えば絶対値は比べられない。** 比べてよいのは同じ周の base と案だけで、
周をまたいだ絶対値の比較はしない。

## まだ測れないもの（PASS の根拠にしない）
