## 公式ページに書いてあること（2026-09-02 取得・本文のみ）

**これは公式が書いている説明であって、製品を触って確かめた事実ではない。**

- Agent Mode: 声で命令すると、アプリをまたいで実行する（メール送信・会議設定など）
- Dictation Mode: 声で入力する
- カーソルの位置を文脈として使う
- 「えーと」「あの」のような filler を自動で取り除く
- Gmail / Slack / Notion / Google Docs / iMessage / WhatsApp / Linear / Chrome / Obsidian と連携
- タスクを覚えて、適切なときに知らせる
- ファイルや文書を横断して探す
- **起動は `fn` キー**
