# J06 — 字幕 → AI に聞く

主な競合: **SuperIntern**（字幕 / 翻訳 / 会議中 AI Chat）

## 課題

会議中に字幕を出し、そのまま「いまの話をまとめて」と聞く。

## 完遂の定義

**窓を増やさずに**字幕から質問へ移れること。

## 測る

| 指標 | 目標 |
| --- | --- |
| window count | 0（同じ面の中身が入れ替わる） |
| 切り替えの操作数 | 少ないほどよい |
| state transition latency | 字幕 → 質問の間 |
| 字幕の遅れ | 発話から表示まで |
| focus theft | 0（会議の入力を奪わない） |
