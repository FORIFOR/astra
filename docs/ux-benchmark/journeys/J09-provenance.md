# J09 — 出所（Astra 固有の加点領域）

競合: 両方とも話者分離・Transcript は持つ。**ここで一段上げる。**

## 課題

AI が拾った「決まったこと」を 1 件選び、**それが本当に言われたか**を確かめる。

## 完遂の定義

1 クリックで、その発言の**時刻・話者・原文**へ辿り着けること。

## 目指す形

```
Decision
Ship macOS first.
Ken · 10:42
"Windows can follow next sprint."
[▶ 10:39 を再生] [Transcript] [Source]
```

行動も同じ:

```
□ Prototype onboarding
Source  Sarah · 14:21
Owner   Shuhei
Due     Tomorrow
[Edit]
```

## 測る

| 指標 | 目標 |
| --- | --- |
| 検証までの操作数 | 1 |
| 出所の網羅率 | 拾った項目のうち出所が付いている割合 = 100% |
| 音声へ戻れるか | 時刻から再生できるか |
| 直せるか | 拾い間違いをその場で直せるか |

## なぜ効くか

AI の結果を「信じるしかない」から「1 クリックで確かめられる」へ変える。
生成物を出す製品すべてに効く差で、速さより効きが長い。

## いまの状態（2026-09-01）

拾った行を押すと、その発言の**前後の文字起こし**が開き、当該行が濃く出る。
同じ場所に「直す」「これは違う」がある。

| | |
| --- | --- |
| 時刻・話者 | ✅ 全行に付く |
| 原文へ 1 クリック | ✅ 行を押すと前後が開く |
| その場で直す | ✅ 直しても出所（誰・いつ）は残る |
| 拾い間違いを消す | ✅ 「これは違う」 |
| その時刻の音声へ戻る | ❌ **再生が未実装。飾りのボタンは置かない** |

同じ文をもう一度出すのは「確かめた」ことにならないので、**前後**を出している。
拾ったものは言い換えていないため、行の文＝発言そのもの。

未計測: 実際のマウス当たり判定（自プロセスの AX が子を返さないため、絵で見る）。

## Workspace の列幅について（この Journey の隣で調べたこと）

「task ごとに列の比率を変える」は、いま入れる先が無い。

| 面 | 実際 |
| --- | --- |
| 録音中の面（唯一の実 Workspace） | 幅 1080。3列は `breakpoint/threeColumn = 1280` 以上の話なので 2 列が仕様どおり |
| `WorkspaceShellView`（3列と breakpoint を持つ） | **どの実画面も使っていない**。selftest だけが作る |
| `MainWindowView`（実際に出る窓） | `NavigationSplitView` + `.inspector`。列幅は利用者が掴んで動かせる |

録音中の面で「拾えたものが無い間は文字起こしへ幅を渡す」を試したが、
**撮って見たら悪化した**。0 秒時点では文字起こしも空なので、広げた分だけ
「まだ発話がありません」の空箱が大きくなる。戻した。

`MainWindowView` で task ごとに列幅を決めるのは、利用者が自分で掴んで
変えた幅を上書きすることになるので、やらない。
