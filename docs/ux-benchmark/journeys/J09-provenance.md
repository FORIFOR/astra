# J09 — 出所（Astra 固有の加点領域）

競合: 両方とも話者分離・Transcript は持つ。**ここで一段上げる。**

## 課題

AI が拾った「決まったこと」を 1 件選び、**それが本当に言われたか**を確かめる。

## 完遂の定義

1 クリックで、その発言の**時刻・話者・原文**へ辿り着けること。

## 目指す形

```
Decision
Ship macOS first.
Ken · 10:42
"Windows can follow next sprint."
[▶ 10:39 を再生] [Transcript] [Source]
```

行動も同じ:

```
□ Prototype onboarding
Source  Sarah · 14:21
Owner   Shuhei
Due     Tomorrow
[Edit]
```

## 測る

| 指標 | 目標 |
| --- | --- |
| 検証までの操作数 | 1 |
| 出所の網羅率 | 拾った項目のうち出所が付いている割合 = 100% |
| 音声へ戻れるか | 時刻から再生できるか |
| 直せるか | 拾い間違いをその場で直せるか |

## なぜ効くか

AI の結果を「信じるしかない」から「1 クリックで確かめられる」へ変える。
生成物を出す製品すべてに効く差で、速さより効きが長い。

## いまの状態（2026-09-01）

拾った行を押すと、その発言の**前後の文字起こし**が開き、当該行が濃く出る。
同じ場所に「直す」「これは違う」がある。

| | |
| --- | --- |
| 時刻・話者 | ✅ 全行に付く |
| 原文へ 1 クリック | ✅ 行を押すと前後が開く |
| その場で直す | ✅ 直しても出所（誰・いつ）は残る |
| 拾い間違いを消す | ✅ 「これは違う」 |
| その時刻の音声へ戻る | ❌ **再生が未実装。飾りのボタンは置かない** |

同じ文をもう一度出すのは「確かめた」ことにならないので、**前後**を出している。
拾ったものは言い換えていないため、行の文＝発言そのもの。
