# J08 — 初回起動 → 最初の成功

主な競合: **両方**

## 課題

インストールしてから、**初めて何かを成し遂げる**まで。

## 完遂の定義

説明を読まずに、最初の 1 つ（録音でも質問でも）が成功すること。

## 測る

| 指標 | 目標 |
| --- | --- |
| first-run success | ≥ 90% |
| 最初の成功までの時間 | 短いほどよい |
| 許可要求の回数 | **使う直前に 1 つずつ**（連続で並べない） |
| 脱落 | 途中でやめた人の数 |
| 空白率 | 最初の画面が何もないと詰まる |

## 注意

いまの Astra は**起動直後に 4 つ並べて聞く**（マイク・画面収録・カレンダー・入力監視）。
Apple も「機能を使う瞬間まで待つ」ことを勧めている。ここは負けている見込み。
