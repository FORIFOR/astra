# J05 — 会議中の Live Notes

主な競合: **SuperIntern**（AI Canvas）

## 課題

会議が始まってから 3 分間、決まったこと・やることが画面に溜まっていくのを見る。

## 完遂の定義

**開始 0 秒から画面が空でない**こと。3 分後に決定・行動が拾えていること。

## 測る

| 指標 | 目標 |
| --- | --- |
| 最初の 1 行までの時間 | 短いほどよい |
| 開始直後の空白率 | 低いほどよい（現状 Astra は白紙） |
| 拾った決定/行動の数 | 多すぎても誤り |
| 誤って拾った数 | 少ないほどよい |
| 出所の有無 | **Astra の加点領域** |

## 注意

**偽の skeleton は置かない。** まだ無いなら「決定を待っています」と正直に出す。
それは空白ではない。
