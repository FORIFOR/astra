# J04 — 会議検出 → 録音開始

主な競合: **SuperIntern**（会議検出から自動ポップアップ）

## 課題

1. Google Meet / Zoom を開く
2. 会議が始まったことを製品が気づく
3. 録音を始める

## 完遂の定義

録音が始まり、**それが画面から分かる**こと。

## 測る

| 指標 | 目標 |
| --- | --- |
| 検出までの時間 | 会議開始から気づくまで |
| 開始までの操作数 | 少ないほどよい（0 = 自動） |
| window count | 0 |
| focus theft | 0（会議の最中に前面を奪わない） |
| 誤検出 | 会議でないものを会議と言った回数 |

## 注意

**検出は開始ではない。** 勝手に録り始める製品は速いが、
それは信頼を削る速さ。「気づいて、聞く」までの速さで competing する。
