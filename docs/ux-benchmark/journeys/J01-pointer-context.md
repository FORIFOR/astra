# J01 — 画面を指して AI に質問

主な競合: **VoiceOS**（カーソルを文脈として扱う UI が本領）

## 課題（3 製品に同じものを与える）

1. Notion を開く
2. 料金表をカーソルで指す
3. 「このプランの問題点を教えて」と話す
4. 回答を得る

## 完遂の定義

指した箇所の内容に**言及した**回答が返ること。
画面全体の要約や、指した箇所と無関係な回答は失敗。

## 測る

| 指標 | 目標 |
| --- | --- |
| task success | 完遂したか |
| completion time | 「指す」から回答が出始めるまで |
| interaction count | 文脈を指定するのに要した操作の数 |
| window count | 0 |
| focus theft | 0 |
| 誤認識 | 音声が別の語に化けた回数 |
| 初回成功率 | 説明なしで通せたか |

## 注意

**VoiceOS が最も強い Journey。** ここで勝てないなら、文脈の扱いで負けている。
「画面を読む」と「指した場所を読む」は別の能力なので、混同しない。
