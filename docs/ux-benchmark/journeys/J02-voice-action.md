# J02 — 声で Email / Calendar を実行する

主な競合: **VoiceOS**（Voice-to-Action）

## 課題

1. 「明日 10 時に田中さんと打ち合わせを入れて」と話す
2. 実行前の確認を見る
3. 承認する
4. 実際に予定が作られたことを確かめる

## 完遂の定義

**外部に実際の変更が起きる**こと。下書きや案の提示だけでは未完遂。

## 測る

| 指標 | 目標 |
| --- | --- |
| task success | 予定が実在するか |
| completion time | 発話から作成完了まで |
| interaction count | 承認までに要した操作 |
| 確認の明瞭さ | 何が起きるか読めば分かるか（SEQ） |
| 取り消せるか | 実行後に戻せるか |

## 注意

外へ出る操作なので、**確認なしで実行したら減点**（速さで勝っても意味がない）。
