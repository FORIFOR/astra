# J07 — 会議終了 → 成果物

主な競合: **SuperIntern**（会議後編集）

## 課題

会議を止めてから、要約・決定・行動が読める形になるまで。

## 完遂の定義

同じ 1 件が recording → processing → ready と姿を変え、
**新しいカードが増えない**こと。

## 測る

| 指標 | 目標 |
| --- | --- |
| 停止から ready まで | 短いほどよい |
| 段階が見えるか | 「処理中」だけで放置しない |
| 直せるか | 拾い間違いを人が直せるか |
| 出所から戻れるか | **Astra の加点領域** |
