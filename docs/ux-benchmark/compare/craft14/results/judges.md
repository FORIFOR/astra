# craft14 — Dock の地を「板」から「gradient / graphite」へ（DS-04 素材感）

sample10 の 3 人が挙げた「地が gradient（素材）」に、Dock の地だけで答えられるかを伏せて訊いた。
影（⑧ で「画面に付属する」と決めた）は動かしていない。

**採用なし。A のまま。** 上下差 10〜16（/255）の gradient は 3 人とも見えない。
見えるまで強くすれば、それは飾りであって素材ではない（craft ④⑥⑦ と同じ結末）。
競合の「gradient dark surface」は、地の階調ではなく**影と壁紙との対比**で読まれている可能性が高く、
それは ⑧ で選ばなかった側。素材感は Dock の面の中では決まらない。
