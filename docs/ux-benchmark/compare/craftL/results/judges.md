# craftL — Library（会議の詳細）の階層を weight / accent で立てる（横展開②）

批評「本文・metadata・タブ・transcript のウェイト差が弱く、目を細めると同じ灰色の塊」に、
**飾りを足さずに** 2 つのレバーだけで答えられるかを伏せて訊いた。
参照 4 面（Linear / Granola / Notion / Apple Notes）はいずれも accent を**参照記号と選択**
にしか使っていない（DESIGN.md §1）。

実測（`images/A|B|C.png`、光。要約 1 行の帯 y145–170 の暗画素、本文列 x270–920 の accent 画素）:

| 案               | 要約の暗画素 | 決定事項の暗画素 | accent 画素（本文列） |
| ---------------- | ------------ | ---------------- | --------------------- |
| A HEAD           | 1199         | 566              | 1044                  |
| B 要約 medium    | 1422 (+19%)  | 566              | 1044                  |
| C B + 話者 muted | 1422         | 566              | 353 (−66%)            |

| judge     | O1 要約の太さ（B/C > A か）                 | O2 話者の色（C だけ灰か）                | 順位      | 採用 |
| --------- | ------------------------------------------- | ---------------------------------------- | --------- | ---- |
| j1 opus   | 3 枚とも「わずかに太い」= 差を見ていない    | C だけ灰（「あなた」を紫と誤認、実測 0） | C > B=A   | C    |
| j2 sonnet | 差なし                                      | **3 枚とも青紫**（実測と矛盾）→ 棄却     | —         | —    |
| j3 opus   | B・C が A より僅かに太い（正）              | C だけ灰（正）                           | C > B > A | C    |

**採用: 話者を muted（C の色の変更）だけ。要約の weight（B）は入れない。**

- 色: 有効 3 名が全員 C を選び、理由が一致する（「名前の青紫が縦 8 つ並び、
  結論より先に表へ目が行く」「色を参照 [1][2][3] と選択に取っておける」）。
  R2（最初に目が行く場所）が A/B は「表の名前の列」、C は「題」に変わる。
- weight: 見えたのは j3 だけ（j1 見えず、j4 cannot tell）。+19% の暗画素は
  DS-02 の 2 段（body regular 16 / primary medium 17）の間で、知覚の下。
  §5「cannot tell が多数なら変えない」。
- 3 名とも「間隔・揃えの粗さに差なし」（R3）。色の 1 レバーで段が立った。

golden: `08-meeting-detail` 光 accent 画素 1420 → 583、暗 2146 → 1072（画面全体）。
限界: 有効な判定者が 1 種（opus）だけ。sonnet は同じ絵で色の差を見ていない。
