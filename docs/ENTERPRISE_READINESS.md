## 次の実地試験に必要なもの

1. Oathra：管理下の受電番号/受電テスター、発信時間、同意、費用上限。
2. AI Meeting：同意した実人間の会話テスターとセッション条件。合成音声やVRMだけの60分試験を代用しません。
3. AISecure：利用権限のある匿名化企業ログ、期待ラベル、調査時間の比較条件。
4. Agent Team：業務を完遂できるモデル/構成で予備試験を合格させ、その後150回×2方式を実行。
5. Genie：通信復帰・初期Profile復帰を修正し、配布物のUI通し試験と障害試験を完了。
6. Launchloom：書き出した素材を製品ごとに仕上げ、動画・LPの実機QAを完了。

## L2/L3は別途合意する

導入相談は既存の各製品サイトの非公開フォームから受け付けます。入力は問い合わせ用に保存され、送信だけで契約・課金は成立しません。公開Issueに顧客情報を載せない運用を維持します。

L2に進める際は、目的・対象データ・責任分界・期間・費用上限・削除・人間承認・成功/中止条件を短いPoC計画にします。L3のSSO/RBAC・監査・保持・監視・復旧・SLA・セキュリティレビューは、全製品へ一律に足さず、顧客要件に応じて別の実装/運用ゲートにします。
