# 映画・旅行・デリバリー

GenieのHomeで **映画・旅行・デリバリー** を開き、希望条件を整理します。
「映画を予約して」「京都旅行を計画して」「マクドナルドを家まで注文して」という依頼でも同じ準備画面を開きます。画像が明示的に添付された質問は通常のAI回答へ進みます。

| 用途             | 今回動くこと                                                                                                                      | 未実装のこと                                                     |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 映画             | 作品・映画館/エリア・日時・人数・予算の整理、条件のコピー、TOHO公式サイトを開く                                                   | 空席取得、座席の仮押さえ、自動購入、予約番号の取得               |
| 旅行             | 行き先・日程・人数・予算の整理、設定中のAIによる旅程案作成、検索対応の接続による最新情報の調査、Workで結果確認、Booking.comを開く | 予約先への自動入力、宿泊・航空券・鉄道の自動予約、予約の一括取消 |
| マックデリバリー | 商品・数量・希望時間・予算の整理、条件のコピー、公式サービスを開く                                                                | 住所の登録、配達エリア判定、カート投入、注文確定、到着追跡       |

**公式サイトを開くだけでは、予約・注文も条件の自動入力も行われません。** 画面には未確定の状態が残ります。公式サービスで内容と合計金額を確認し、確定してください。現在はTOHOとBooking.comの入口を用意しており、全映画館・全旅行事業者への接続ではありません。

## 料金と個人情報

- 準備画面の表示・編集・コピーでは言語モデルを呼びません。サービスに条件を自動送信せず、住所も推定しません。
- **旅程案を作る** はWeb検索なしでたたき台を作成し、最新情報が未確認であることを明記します。**最新情報を調べる** は検索が可能な接続を使います。いずれも押したときだけ、既存の実行経路へ依頼します。選択中の提供者の料金が適用されます。Web検索のないローカル/APIモデルから検索結果を生成することは禁止し、未対応を返します。別の有料接続を勝手に有効化しません。結果は既存のWorkに保存され、開き直すたびに生成し直しません。
- 住所・電話番号・支払い情報は、配達/予約サービス側で入力します。旅程をAIに依頼する場合は、画面に入力した希望と依頼メモが選択中の実行経路へ送られます。
- 希望条件はアプリが起動している間、種類ごとに保持します。閉じて開き直しても残りますが、アプリ終了後の永続保存は今回の範囲に含みません。「条件をコピー」で控えを残せます。

## 自動確定に進むための残件

予約/注文サイトの実行アダプターと、本人のアカウントを使った検証が必要です。今あるConnectionsのGoogle/Microsoft連携だけでは、他社の予約・注文権限は得られません。

実行アダプターでは、少なくとも以下を一連で実装・検証してから自動予約を有効にします。

1. 実在する候補と在庫、日時、人数/数量、税・手数料込みの最終価格、取消条件を取得する。
2. 利用者が確認した内容に実行を結び付け、価格・日時・宛先・商品が変わったら再確認する。
3. 最終操作を重複実行しない。応答が失われたときは再購入せず、注文履歴・予約番号を確認する。
4. サービスから返った予約/注文番号と確認済みの状態を保存し、失敗・未確認・完了を区別する。
5. ログイン、本人認証、サービスが要求する操作を本人へ引き継ぎ、戻ったところから続行する。

## 確認した公式資料（2026-09-13）

- [TOHO vit購入手順](https://www.tohotheater.jp/vit/vit_buy.html)：劇場・日時、座席、券種、支払いという購入手順。
- [マックデリバリーの利用手順](https://www.mcdonalds.co.jp/shop/mcdelivery/)：アカウント、お届け先と日時、商品、支払いの流れ。
- [マックデリバリー公式ページ](https://www.mcdonalds.co.jp/mcdelivery/)：確認時点でWebのクレジットカード/Google Payはメンテナンスにより利用不可、これらの支払いは公式アプリへの案内あり。この一時的な制約をアプリ内の固定文言にはしない。
- [Booking.com認証](https://developers.booking.com/demand/docs/development-guide/authentication)：統合用APIにはパートナーのAPIキーとaffiliate IDが必要。
- [Booking.com Orders API](https://developers.booking.com/demand/docs/orders-api/overview)：価格をpreviewで確認し、そのtokenでcreateする。公式サイトのリンクを開く機能とは別物。

実在の映画・旅行・商品の予約や注文はこの開発作業では実行していません。
