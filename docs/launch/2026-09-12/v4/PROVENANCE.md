# Astra — 見る。聞く。進める。

[42秒の製品紹介](https://www.youtube.com/watch?v=uSIxI4MGzrg) · [ホームページ](https://astra-forifor.forifor.chatgpt.site/) · [参照と演出判断](DIRECTION.md)

## 実際に行ったこと

架空のPULSEダッシュボードをPreviewで表示し、macOSのウインドウ撮影で取得。Astraのスクリーンショット検知から画像付きの質問を送信した。⌘⇧3を押した瞬間の収録ではない。グラフの幅は模式的な表示で、分析に使う値は数字で示している。

依頼は「この数字から、改善の優先順位を3つ教えて。理由と次の一手も、短く。」。実際のGatewayとagent-hostを経由し、接続したCodexが回答を生成した。2026-09-11 21:11:58.891Zから21:12:12.306Zまで、約13.4秒。スクリーンショットと質問は外部モデルへ送信している。

Astraの「保存…」とmacOSの保存ダイアログを操作し、Markdownへ保存。完了後にWorkの「完了」フィルターで回答を確認した。[保存文書](answer-from-astra.md)は実際のエクスポートで、内容を編集していない。

収録用にアプリのデータ領域とアカウントを分離した。初回はGeneral Assistant未インストールで依頼が実行されず、テスト用アカウントに標準プラグインを設定してから成功した。製品の初期設定が不要だった、一発で成功した、とは主張しない。映像のためにアプリのUIや回答を差し替えていない。日本語の質問は実際の入力欄に貼り付けた。IMEでの逐字入力の検証ではない。

## 編集

主版1920×1080と、別の構図で編集した1080×1920。ともに42秒・60fps。元の画面収録は可変フレームレートのため、全体を30fpsへ正規化してから編集した。カメラと字幕は60fpsで合成している。アプリそのものが60fpsで変化しているという意味ではない。

| 時間    | 場面                                                                   |
| ------- | ---------------------------------------------------------------------- |
| 0–4秒   | Astraと質問画面を紹介                                                  |
| 4–9秒   | 架空のダッシュボードから、質問への案内                                 |
| 9–18秒  | 実際の質問欄と送信。生成待ちは短縮を明示                               |
| 18–28秒 | 実際の回答。縦版の大きな文章は「実際の回答より」と表示した編集上の抜粋 |
| 28–33秒 | 本物の保存ダイアログと保存完了表示の静止画                             |
| 33–37秒 | Workで完了した依頼を再確認                                             |
| 37–42秒 | GitHubへの案内とプレビュー版の必要設定                                 |

参照した第三者の映像、UI、音楽は素材として使用していない。BGMはこの映像用にコードで作曲・合成した。ナレーションなし。今回の音声合成API呼び出しは0回。生成用のCodexにはログイン済みCLIの利用枠が適用される。

## 検証と制限

- 両版とも2520フレーム・42秒、H.264＋AACステレオ。全編デコードでエラーなし。
- 音量は約−20.13 LUFS、真のピーク−6.90 dBTP。音割れなしの数値確認。音楽の好みを客観的に検証したという意味ではない。
- 入力、回答、保存、終了画面の代表フレームを目視。縦版の回答の切れと、保存完了を見せない切り取りを修正した。
- [メディアの寸法・音量・SHA-256](media-validation.json)を保存。
- アプリのソースはこの変更では触っていない。今回の映像制作は製品全体のrelease=go判定ではない。

## 再編集

`film.swift`が実際の収録と静止画を合成する。`fixture.swift`が架空の入力データ、`score.py`がオリジナルの音楽を生成する。`film.swift`は第1引数に素材ディレクトリ、第2引数に`web`または`social`を取る。`--samples`は構図確認専用で、その出力動画は公開しない。

元収録はMacの`/tmp/astra-launch-v4`、完成動画と字幕は`~/Downloads/Astra-Launch/v4`に保存。大きな動画をこのGitリポジトリへ入れず、ホームページの配布用アセットとして公開している。
