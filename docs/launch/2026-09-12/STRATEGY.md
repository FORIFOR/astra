# Astra public developer preview — 2026-09-12

## Audience and message

Start with Mac users who already use AI and developers willing to run a local backend. Lead with one observable workflow: capture a screenshot, ask a specific question, reopen the answer. A broader claim of fully autonomous business outcomes is not demonstrated by this preview.

The landing page uses an actual native app capture, a short edited recording of real operation, a visible setup requirement, and a direct GitHub link. English and Japanese copy address the existing Japanese product UI and an international developer audience. A public workflow/pilot issue is the initial business inquiry path; no pricing, sales result, or client endorsement is invented.

## Research reviewed

- https://screenpipe.com/ — first-party positioning, short product film, download and GitHub links, and model choice. Adopted a clear single-sentence promise and prominent actual product demonstration, not its layout or its popularity claims.
- https://www.reddit.com/r/SideProject/comments/1r4mdmg/i_record_every_pixel_on_my_screen_247_and_let_ai/ — a concrete firsthand project use case presented to an appropriate maker audience.
- https://www.reddit.com/r/tauri/comments/1qw72rx/we_built_a_full_screen_capture_ai_search_app_with/ — a technical community context for an actual desktop product.
- https://docs.ollama.com/api/openai-compatibility and https://ollama.com/library/qwen3.5:9b — local model interface and image-model availability checked against primary sources.

These are examples of presentation and channel fit. They do not establish that any design causes stars or guarantees reach. The historical X inspiration could not be retrieved; its video was not used as evidence or copied.

## Publication safeguards grounded in this launch

No fake stars, testimonials, counters, waitlists, usage claims, or engagement purchases. No contact scraping or unsolicited bulk messages. Only the user's own authenticated account may publish the launch post. Test media contains a synthetic error screen and a local test identity, not personal work. The public repository currently has no project-wide open-source license, so copy says public codebase/developer preview.

## Baseline and measurement

At the start of this launch, FORIFOR/astra was already public and had 0 GitHub stars. Its repository description and homepage fields were empty; latest published release was v0.1.1. Record actual stars, repository traffic (where available), release downloads, and workflow issues after publication. Do not substitute estimates for these measurements. The landing page has no tracking cookies, advertising pixels, or model calls.

## Validation boundary

The complete verify-all run passed in the available Mac environment after a dedicated local test host and general task capability were configured. This is not a claim that every production release acceptance gate is closed. A local text-classification demo produced repetitive output and was rejected as promotional proof. Model quality remains task-dependent.
