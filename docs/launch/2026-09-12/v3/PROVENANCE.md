# 実演の来歴と検証

自作の手描き風スケッチをPreviewで表示し、macOSのウインドウ撮影で取得した。Astraのスクリーンショット検知から画像付きの依頼を送信。今回は⌘⇧3キーを押した映像ではない。

最終作品はAstraの実際のGatewayとagent-hostを経由し、接続したCodex CLIが生成。成功した生成は2026-09-11 20:12:40.623Zから20:15:40.188Zまで、約180秒。画像と本文を外部モデルに渡した。ローカル完結・即時生成・一発成功とは表現しない。

Astraの「保存…」でMarkdown文書を保存し、`<!DOCTYPE html>`から`</html>`までを抽出した。HTMLとJavaScriptを生成後に手修正していない。保存文書と抽出HTMLの一致を確認。Astra内部の自動プレビューや自動公開を示す映像ではない。

映像は実際のMacアプリとChromeの画面収録から編集。生成待ちと操作間の待ちを削除し、注目箇所を拡大した33秒。縦版と横版で拡大箇所を変えた。操作は検証エージェントが行った。音声はGoogle Cloud TTS ja-JP-Chirp3-HD-Aoedeの合成ナレーション。音楽はAstra用にローカルで作曲した素材。第三者の動画・音楽・キャラクターは使用していない。

## 不採用・制限

- qwen3.5:9bの試作2件は軌道や操作の不具合があり不採用。
- 参照を含む依頼1件は確認質問となった。タスク生成前と確認して依頼し直した。
- Codexの初回は120秒の既定時間で失敗。自動再実行はしていない。
- 今回、Codexの実行時間を環境設定で1〜600秒に指定可能にした。300秒の設定で約180秒の生成が成功。既定の120秒は維持。185件のagent-hostテストとTypeScriptビルドが成功。
- 長時間生成の完了後はAstraの「状況を確認」を押して取り込んだ。自動更新が常に完了まで続くとは主張しない。
