# infra/db

Plain-SQL migrations are the **source of truth** for the schema
(product spec §18). No ORM owns the schema.

Tooling: [`dbmate`](https://github.com/amacneil/dbmate) — `brew install dbmate`.

```sh
cp ../../.env.example ../../.env      # then export DATABASE_URL
pnpm db:new create_tasks              # new migration pair
pnpm db:migrate                       # apply
pnpm db:status
```

`schema.sql` is generated by dbmate after each `up` and must be committed.

Typed access lives in `packages/db` (Kysely `Database` interface + tenant guard).
See `docs/spec/phase-0-implementation-spec.md` §5.
